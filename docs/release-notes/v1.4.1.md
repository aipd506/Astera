## Fixes

* **A CLI that is installed no longer shows as missing on Windows.** After the update to 1.4.0, Astera
  could say Codex or Claude Code was not installed, because it had been restarted with an old copy of
  the environment from before that CLI was added to your PATH. Astera and its background Host now read
  the PATH Windows keeps when they start, and read it again before starting a CLI they cannot find, so
  a CLI you install while they run is found without a restart.
* **Settings no longer label anything experimental.** Work unit tracking, Agent browser, Agent app
  workspace, Smart Resume and Job Continuity are ordinary settings now.
